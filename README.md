House Price Prediction Using Machine Learning

Project Overview

This project predicts house prices using machine learning and Python. It aims to estimate house prices based on the features provided by the user.

Objectives

- Understand the basics of machine learning.
- Use Python for data processing and prediction.
- Explore housing data using a CSV dataset.
- Build a simple interface using Streamlit (if configured).

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- CSV dataset

Project Files

- "app.py" – Main application file.
- "house_data.csv" – Housing dataset.
- "house_data.py" – Housing data-related code.
- "house_price.py" – House price-related code.
- "ml_house_price.py" – Machine learning code.
- "predict_price.py" – Price prediction code.
- "read_data.py" – Code for reading data.

How to Run

1. Install Python.
2. Install the required libraries.
3. Open the project folder in VS Code.
4. Run the application using Streamlit if "app.py" is configured for Streamlit.

Conclusion

This project provides beginner-level experience in Python, data handling, and machine learning for house price prediction.
